# Novaris Pokédex Android

Source package and GitHub Actions build for the local Novaris Pokédex Android app.

The APK is intentionally built without bundling the >100 MB Pokédex HTML. After installation, import the current `Pokedex_Vxx_xx.html` directly on the Android device via the ↻ menu.

The full source package is stored as `Novaris-Android-v0.3.0-source.zip` and unpacked by GitHub Actions for the build.
